そのほかの条件

  • 帽子をかぶらない(無帽)
  • 正面を向く
  • 髪が眉・目・耳にかからないこと(パスポート)
  • 両耳が見えること、口を閉じて目を開けること(ビザ)
  • 色付きの眼鏡は不可。ビザは太いフレーム・反射する眼鏡も不可
  • パスポートのアプリ申請では、明るい色の服だと返却されることがあると大使館が書いています
  • ビザは光沢のある写真用紙(普通紙・布目紙は不可)
  • 「中国領事」アプリでパスポートを申請するときの電子写真は別規格(JPEG・30〜80KB)です。このアプリ1.0が作るのは印刷用のL判です。ビザの枚数は申請センターによって書き方が違うため、東京センターの案内でご確認ください。

コンビニでの印刷のしかた(L判・3社)

L判は89×127mmです。アプリはL判の画像(1051×1500px)に同じ写真を並べて保存するので、普通の「写真プリント」のL判で印刷して切るだけです。

セブン-イレブン / 7-Eleven

  1. 保存したL判の画像を、スマホからコピー機へ送ります。アプリは3つ:「かんたんnetprint」(登録不要・予約日の翌日まで有効)、「netprint」(登録して使う・予約日から30日有効)、「セブン-イレブン マルチコピー」。機械でQRコードを読み取ってWi-Fiで送ることもできます。
  2. コピー機で「写真プリント」を選び、送った画像を呼び出します(予約番号またはQRコード)。
  3. 用紙サイズは「L判」(89×127mm)を選びます。「証明写真プリント」は選ばないでください(別メニューで高くなります)。
  4. 料金は1枚40円です。印刷したら、切り取り線に沿ってはさみで切ります。

ローソン / Lawson

  1. 保存したL判の画像を、専用アプリ「PrintSmash」(写真)でコピー機へ送ります。
  2. コピー機で「写真プリント」を選び、送った画像を呼び出します(予約番号またはQRコード)。
  3. 用紙サイズは「L判」(89×127mm)を選びます。「証明写真プリント」は選ばないでください(別メニューで高くなります)。
  4. 料金は1枚30円です。印刷したら、切り取り線に沿ってはさみで切ります。

ファミリーマート / FamilyMart

  1. 保存したL判の画像を、「ファミマネットワークプリント」アプリ(無料)または「PrintSmash」でコピー機へ送ります。
  2. コピー機で「写真プリント」を選び、送った画像を呼び出します(予約番号またはQRコード)。
  3. 用紙サイズは「L判」(89×127mm)を選びます。「証明写真プリント」は選ばないでください(別メニューで高くなります)。
  4. 料金は1枚30円です。印刷したら、切り取り線に沿ってはさみで切ります。
注意:「証明写真プリント」(L判で¥200–250)は別メニューです。写真プリントのL判なら1枚¥30–40です。セブン-イレブンは「証明写真プリントは、パスポート申請には適しません」と書いています。

アプリで作る

撮影と、透かし入りの仕上がりの確認は無料です。L判の画像を保存するときだけ、全用途で¥500の買い切り(サブスクなし・広告なし・ログインなし)。写真はスマホの中だけで処理し、サーバーには送りません。
